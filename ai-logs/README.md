# AI 对话记录 · ai-logs/

本目录保存构建 wick 期间的 AI 对话记录。

## 记录方式与诚实声明

**这些是整理过的记录，不是逐字转录。** 我们明确说明这点，因为把整理稿说成原始转录是一种更糟的欺骗。

- 保留了：每次指令的实质内容、AI 给出的方案原文、关键决策、被测试抓出的每一个错误，以及错误修复前后的真实数字。
- 省略了：重复的读文件/跑命令往返、中间态输出、以及与本作品无关的系统噪声。
- 没有删除任何**不利**内容：模型犯的错在下面第 4 节逐条列出，包括一个会把结论方向搞反的公式错误。

整理范围：模型输出的完整方案、测试结果与数字均按原样保留；只压缩了与结论无关的机械往返。

## 与 AI_USAGE.md 的关系

`AI_USAGE.md` 是**声明**（用了什么、谁决定什么、错在哪里、拒绝了什么）；
本目录是**过程证据**（这些判断是在哪一步、被什么证据推动的）。
